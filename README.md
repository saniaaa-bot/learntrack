# LearnTrack - Student Learning & Quiz Management System

LearnTrack is a modern, full-stack educational platform built with Laravel. It allows instructors to create courses and quizzes, while students can enroll, attempt quizzes, and track their scores. 

## 🚀 Features

- **Role-Based Authentication:** Separate flows for Instructors and Students.
- **Instructor Panel:** Create courses, add multiple-choice questions, and manage content.
- **Student Panel:** Browse available courses, take quizzes with an interactive UI, and view detailed results.
- **Automated Scoring:** Quiz scores are calculated securely on the server side.
- **Attempt History:** Students can view their previous attempts and scores for any course.
- **Modern UI:** A premium, fully responsive Dark EdTech theme built with Tailwind CSS.

## 💻 Tech Stack

- **Backend:** Laravel 12 (PHP 8.2)
- **Frontend:** Blade Templates, Tailwind CSS, Vanilla JS
- **Database:** SQLite
- **Authentication:** Laravel Breeze
